# TerraTech - Data Directory Layout

This directory houses raw, sample, processed, and validation datasets for the TerraTech platform.

## Directory Structure

```
data/
├── raw/                  # Place original official government datasets here (when available)
├── sample/               # Synthetic demonstration dataset (2,500 records)
│   └── terra_land_acquisition_synthetic.csv
├── processed/            # Cleaned data and ML-ready training datasets
│   ├── cleaned_land_acquisition.csv
│   └── ml_dataset.csv
└── validation/           # Automated profiling and quality reports
    ├── profiling_report.json
    ├── profiling_report.md
    └── quality_report.txt
```

### 1. `data/raw/`
- Designed to hold real government land acquisition records when provided.
- Kept strictly immutable. Files placed here are never modified or overwritten.

### 2. `data/sample/`
- Contains `terra_land_acquisition_synthetic.csv`, a realistic, non-deterministic 2,500-record dataset created specifically for prototyping, model training, and testing.

### 3. `data/processed/`
- `cleaned_land_acquisition.csv`: Output from `data_pipeline/clean_data.py`. Deduplicated, missing values imputed, text standardized.
- `ml_dataset.csv`: Output from `data_pipeline/feature_engineering.py`. Feature-engineered dataset with leakage variables strictly isolated.

### 4. `data/validation/`
- `profiling_report.json` & `profiling_report.md`: Statistical distribution, missingness, and outlier profile generated by `data_pipeline/profile_data.py`.
- `quality_report.txt`: Automated verification report produced by `data_pipeline/validate_data.py`.
